Native Android Mobile App

A fully functional Android mobile application developed in Android Studio using Java. The app was designed with real-world usability in mind — featuring a clean interface built with XML layouts, smooth navigation between screens using Activities and Intents, and data handling through local storage. The project followed Android development best practices throughout the build.

Tech Stack
Android Studio Java XML Layouts Activities Intents SQLite
What I Used

Android Studio

The official IDE for Android development. Used for writing code, designing layouts visually, and running the app on an emulator.

Java

Core programming language for the app logic — handling user interactions, data processing, and navigation between screens.

XML Layouts

Used to design and structure every screen in the app — placing buttons, text, and inputs using ConstraintLayout for all screen sizes.
